# NIBBLE

Welcome to nibble! nibble is a short and size-compact video game that can fit inside a QR code!

Nibble was written entirely by me with no outside assistance outside of the use of stack overflow for debugging

Made using html, css and javascript. no external APIs, CDNs, or other tools. 

mechanics are simple and self-explanatory. hit the button and get points. use points to get passive income,
or increase the effectiveness of your own clicks.
